## 第一步：更新系统并安装系统依赖

首先需要确保系统是最新并且安装zephyr编译所需的底层工具(Cmake,Ninja和设备树编译器)

打开终端，运行以下命令：

```
sudo apt update
sudo apt upgrade -y

# 安装核心开发工具和依赖
sudo apt install --no-install-recommends git cmake ninja-build gperf \
  ccache dfu-util device-tree-compiler wget \
  python3-dev python3-pip python3-setuptools python3-tk python3-wheel xz-utils file \
  make gcc g++ libsdl2-dev libmagic1 python3-venv
```

---

## 第二步：创建python虚拟环境

最新的Raspberry Pi OS默认限制了全局pip安装，需要创建python虚拟环境

打开终端，运行以下命令：

```
# 创建工作目录
mkdir ~/zephyrproject
cd ~/zephyrproject

# 创建并激活虚拟环境
python3 -m venv ~/.venv
source ~/.venv/bin/activate
```

注意：每次打开新终端准备开发zephyr时，都需要先运行 `source ~/.venv/bin/activate`来激活环境

---

## 第三步：安装west工具并获取zephyr源码

```
# 在激活的虚拟环境中安装 west
pip install west

# 初始化 west 工作区（这会自动拉取 Zephyr 的核心代码，可能会花一点时间）
west init ~/zephyrproject

# 进入工作区并更新所有相关的模块和仓库
cd ~/zephyrproject
west update
```

---

## 第四步：导出CMake包并安装python依赖

```
# 导出 Zephyr 的 CMake 包
west zephyr-export

# 安装所需的 Python 依赖项
pip install -r ~/zephyrproject/zephyr/scripts/requirements.txt
```

---

## 第五步：安装zephyr SDK

Zephyr SDK 包含了交叉编译所需的工具链（Toolchains）。因为主机是树莓派（基于 ARM 架构），**必须**下载专门为 `aarch64` Linux 宿主机构建的 SDK，而不是常规的 x86 版本。

```
cd ~
# 下载适用于 aarch64 的 SDK（以 0.17.0 版本为例，这是目前较新的稳定版）
wget https://github.com/zephyrproject-rtos/sdk-ng/releases/download/v0.17.0/zephyr-sdk-0.17.0_linux-aarch64_minimal.tar.xz

# 解压 SDK
tar xvf zephyr-sdk-0.17.0_linux-aarch64_minimal.tar.xz

# 进入 SDK 目录并运行安装脚本
cd zephyr-sdk-0.17.0
./setup.sh
```

---

## 第六步：编译一个示例项目（验证环境）

编译QEMU hello world项目

```
# 确保在 zephyr 目录下
cd ~/zephyrproject/zephyr

# 编译针对 ARM Cortex-M3 模拟器的 Hello World
west build -b qemu_cortex_m3 samples/hello_world

# 运行模拟器
west build -t run
```

## 问题汇总

1. 第六步编译会失败：原因SDK版本不符合最新的要求，需要用以下命名更新SDK版本

   ```
   # 确保你的 Python 虚拟环境处于激活状态
   source ~/zephyrproject/.venv/bin/activate

   # 进入 zephyr 主目录
   cd ~/zephyrproject/zephyr

   # 自动匹配正确的 SDK 版本，并仅下载 arm-zephyr-eabi 工具链
   west sdk install -t arm-zephyr-eabi

   # 强制全新编译 Cortex-M3 模拟器目标
   west build -p always -b qemu_cortex_m3 samples/hello_world

   # 启动模拟器运行
   west build -t run
   ```
2. 给树莓派配置局域网共享代理

   用clash，在设置或者主界面中找到"Allow LAN"并且打开，记住端口号，然后获取到电脑的IP，通过一下命令配置树莓派代理

   ```
   # 设置 HTTP 和 HTTPS 代理
   export http_proxy="http://192.168.1.100:7890"
   export https_proxy="http://192.168.1.100:7890"

   # 让 Git 也强制走这个代理
   git config --global http.proxy http://192.168.1.100:7890
   git config --global https.proxy http://192.168.1.100:7890
   ```
3. ssh proxy

   ```
   Host github.com
       User git
       # 对于 Ubuntu/树莓派 Debian 系统：
       ProxyCommand nc -X 5 -x 192.168.31.202:7890 %h %p
   ```
